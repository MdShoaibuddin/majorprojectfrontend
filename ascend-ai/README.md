# Ascend AI — Student Productivity & Career Assistant

A premium, responsive AI student workspace prototype built in React and TypeScript. It includes a dashboard, study assistant, career mentor, coding helper, planner, calendar, chat, document library, analytics, and settings demo experience with mock data.

## Run locally

```bash
cd ascend-ai
npm install
npm run dev
```

## Build for production

```bash
npm run build
```

## Notes

- This is a frontend prototype using realistic mock data.
- AI features are clearly labeled as demo or simulated.
- The design is modular and ready to be wired to a real backend API later.
